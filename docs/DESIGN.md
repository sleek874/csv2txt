# 離線資料轉換 — 固定資料與產品規格

## 1. 目的與狀態

本工具在瀏覽器內提供單一、批次、離線資料工作區：

- 同一個檔案選擇區接受 CSV、XLS、XLSX、臺灣政府 BIG-5E TXT 及 ZIP。
- 每個支援檔案由自動選定的 input adapter 解析為共用內部表示。
- 使用者先獨立選擇輸入與輸出 `TXT`、`CSV` 或 `XLSX`；畫面不顯示編碼名稱。
- 所有支援檔案都會保留，但只有目前輸入格式進入工作樹、預覽與輸出。

本文件定義目前主要版本的固定契約。舊設定檔、舊 localStorage、方向式 UI、舊 DOM selector 與舊行為相容層已移除，不屬於支援範圍；尚未完成的能力不得在 UI、README 或部署說明中宣稱已完成。

## 2. 核心原則

1. 所有敏感資料只在使用者瀏覽器記憶體中處理。
2. 資料格式固定，不提供使用者修改欄寬、對齊、空白策略或必填規則。
3. 解析、驗證、自動修正、序列化是不同階段，不把資料修正藏在 parser 或 writer 裡。
4. 任何修改都必須可追蹤，並在輸出前再次驗證。
5. 不靜默截斷、補零、更名、跳過錯誤或改變路徑。
6. UI 只顯示欄位編號，不顯示業務欄位名稱。
7. 大型批次只呈現目前需要的摘要與分頁資料，不一次渲染全部內容。
8. 來源格式只決定 input adapter，不建立方向模式、分頁或平行工作流程。
9. 輸出格式決定 serializer 與格式相容性 gate；共用 IR 不因格式切換而重建或改寫。
10. 只要資料結構仍可可靠判讀，encoding repertoire 問題不取消勾選也不阻止下載。未知輸入片段在 IR 使用 `？`，Unicode 輸出保留未解決 PUA，TXT 無 mapping 字元在輸出邊界改為 `？`；`■` 只用於預覽。

### 重大更新契約

重大更新先修改並確認本文件，再開始廣泛實作。提案必須簡短定義：

- 使用者要完成的結果，以及明確不在範圍內的項目。
- 必須維持的資料、bytes／CRLF、隱私、安全、離線與可及性契約。
- 允許改變或移除的現有行為；未列出的行為視為必須保留。
- 第一個可端到端使用、可獨立驗證的最小版本。
- 可觀察的完成條件、測試與仍需人工確認的證據。

產品行為只在本文件定義；模組責任與 dependency 決策屬於
[架構文件](ARCHITECTURE.md)，實作順序屬於 [更新計畫](ROADMAP.md)。目前
需求不包含的舊路徑應連同對應 types、tests 與文件一起移除，不建立隱藏
fallback 或 migration。

## 3. 固定 208-byte profile

| 欄位 | 寬度 | 主要規則 | 額外驗證與輸出規則 |
|---:|---:|---|---|
| 1 | 1 | `^[AB]$` | 必填 |
| 2 | 2 | `^[0-9]{2}$` | 必填；保留前置零 |
| 3 | 1 | `^[1-6]$` | 必填 |
| 4 | 10 | `^[0-9]{10}$` | 必填；視為文字，不自動補零 |
| 5 | 10 | `^[A-Z0-9]{5,10}$` | 移除空白後轉大寫；不是有效國民身分證或新式外來人口統一證號時顯示警告；若有效，性別與欄位8不符時依證號修正欄位8並顯示警告 |
| 6 | 8 | `^[0-9]{8}$` | 必填；真實西元日期且嚴格早於臺北當地今天 |
| 7 | 12 | `^.+$` | 必填；BIG-5E TXT 替代後不得超過 12 bytes |
| 8 | 1 | `^[12]$` | 必填；欄位5為有效證號時，以 `1↔8`、`2↔9` 對應性別；不一致時依證號改為 `1` 或 `2` 並顯示警告 |
| 9 | 120 | `^.+$` | 必填；BIG-5E TXT 替代後不得超過 120 bytes |
| 10 | 15 | `^[0-9()+#-]{1,15}$` | 來源可空；在輸出修改階段補為 `0000000000`；最終值必須通過規則 |
| 11 | 10 | `^[A-Z][12][0-9]{8}$` | 必填；移除空白後轉大寫；必須通過臺灣身分證檢查碼 |
| 12 | 1 | `^[ABCD]$` | 必填 |
| 13 | 8 | `^[0-9]{8}$` | 必填；真實西元日期且嚴格早於臺北當地今天 |
| 14 | 8 | `^(?:[0-9]{8})?$` | 有值時須為真實日期、早於今天且晚於欄位13 |
| 15 | 1 | `^[1-4]?$` | 與欄位14同時有值或同時空白 |

寬度陣列固定為：

```text
[1, 2, 1, 10, 10, 8, 12, 1, 120, 15, 10, 1, 8, 8, 1]
```

BIG-5E TXT 的總寬度固定為 208 bytes。所有值靠左，右側以半形空白 byte `0x20` 補足欄寬；CSV／XLSX 不套用 BIG-5E byte 寬度 gate。

## 4. 正規化

### 4.1 CSV／Excel input adapter

CSV、XLS 與 XLSX 每個來源儲存格依序處理：

1. 保留必要的原始值供問題或變更說明使用。
2. 移除全部 Unicode 空白字元，不只頭尾空白。
3. 所有半形 `?`（U+003F）轉成全形 `？`（U+FF1F）；不套用 NFKC，也不改寫其他相似符號。
4. 欄位5與欄位11轉成 ASCII 大寫。
5. 寫入共用內部表示。

不執行數字推斷、日期格式轉換、自動補零或科學記號還原。

### 4.2 BIG-5E TXT input adapter

1. 以 byte 檢查換行與 record 邊界；空白或只含空白的實體行先移除並計數。
2. 每個其餘 record 必須在不含 CRLF 時恰為 208 bytes。
3. 依固定欄寬切成 15 個 byte slice。
4. 只使用數位發展部全字庫官方對照表解碼臺灣政府 BIG-5E，不使用 WHATWG／HKSCS 對照。欄位內無法對照的連續 byte segment 在 IR 以一個 `？` 代替，前後可確認的內容仍保留；issue 只記錄該 segment、欄內位置與替代字元位置，預覽才顯示 `■`。
5. 只有 record 寬度或換行結構不成立時才把整列列為無法解析；局部 byte 問題仍建立資料列並預先勾選。
6. 移除右側 `0x20` padding。
7. 移除剩餘空白字元並寫入共用內部表示。

不得以文字字元位置切割 BIG-5E 固定寬資料。

### 4.3 空白列

正規化後每個儲存格都為空時，該列視為空白列並移除。這包含：

- 完全空白的 CSV 行。
- 只有半形、全形或其他 Unicode 空白的行。
- 每個 Excel 儲存格皆空白的列。
- `,,,` 這類所有解析欄位皆空的 CSV record。

移除的列只保留原始來源列號並計入「空白列」摘要，不產生 warning、不進入預覽，也不得因後續欄位10補值而復活。

## 5. 內部表示與兩次驗證

所有 input adapter 都產生同一種 15 欄邏輯資料。每一列至少保留：

- 原始來源列號。
- 是否保留於輸出。
- 15 個正規化值。
- 欄位與列層級 issue。
- 修改前後差異與原因。

檔案另保留空白列號與無法解析的來源記錄。無法解析記錄保存來源列號、使用者可理解的原因、必要的原始內容，以及按需展開的技術證據；它不建立假 IR 列，也不能勾選。成功解析的原始資料不重複保存。`normalizedValue` 是主要 Unicode 值，`finalValue` 只在修正時 copy-on-write。

內部值以 Unicode 為共同表示。CSV 或試算表來源若含舊式 Windows CP950 外字位置的 BMP Private Use Area 字元，自動修正階段會查詢由官方完整 CNS／Unicode、BIG5-2003、BIG-5E、電信、稅務、工商、財稅及各地政對照表產生的 recovery-only table。標準 BIG5 對照優先；其餘只有所有可用官方來源得到單一 formal Unicode candidate 時才還原。成功時保留 normalized original、寫入 final value 與 change log，並顯示簡短 verification warning；無法唯一還原的 BMP、Plane 15 或 Plane 16 PUA 保留原 code point 並顯示簡短 error。CSV／XLSX 仍輸出該 PUA；TXT 在輸出邊界以 `？` 代替。不得使用 HKSCS fallback，也不得在結果有歧義時猜測字義。

處理順序固定為：

1. 來源結構與欄位驗證。
2. 明確的列篩選與值自動修正。
3. 對保留資料執行最終驗證。
4. Section 2 對已勾選列執行所選 output codec 的相容性驗證，再決定是否可序列化。

欄位5有效證號推導欄位8性別、欄位10補 `0000000000` 與舊系統字元還原都是來源驗證後、最終驗證前的內建自動修正，不是 parser default。這些自動修正套用於共用內部表示，與來源格式及最後選擇的輸出格式無關，必須留下 kind、before、after 與 reason，並使該列歸入 warning。

## 6. 嚴重程度

- `error`：可解析的該列預設納入輸出且不形成一般輸出 gate；使用者可在預覽中明確取消勾選。
- `warning`：可解析的該列預設納入輸出且不形成一般輸出 gate；包含來源 warning 與任何自動修正。
- `rejected`：來源列無法可靠解析；不可勾選，保留原始證據，並阻止不完整批次輸出。
- `output notice`：只屬於 Section 2 的所選格式，不寫回 IR；BIG-5E 沒有 mapping 時逐字以 `？` 代替，保持勾選且不阻止下載。
- `fatal output error`：替代後仍超出固定 byte 欄寬等無法建立合約輸出的問題；只計這類 output problem，並停用下載。
- `valid`：沒有 error、warning 或自動修正，可直接輸出。
- `excluded`：使用者或固定檔案篩選明確排除，不算 error，但必須計數。

Section 1 的來源記錄滿足 `來源記錄 = 空白列 + 無法解析 + 資料`，資料列滿足 `資料 = 正確 + 錯誤 + 警告`。同列同時有 error 與 warning 時只計 error，但展開後仍列出全部 issue 與 change。

任何欄位含 `?` 或 `？` 時，正規化值一律使用 `？` 並顯示 warning，提醒它可能是原始內容或先前轉碼的替代字元。Decoder 產生的 `？` 使用更具體的 byte issue，不重複一般問號 warning。

欄位5不是有效國民身分證或新式外來人口統一證號時為 warning；有效欄位5與欄位8性別不一致時，依證號覆寫欄位8並顯示 warning。欄位11仍只接受國民身分證，格式或檢查碼錯誤時為 error。

## 7. 日期與證號

### 日期

- 嚴格接受八位 ASCII 數字 `YYYYMMDD`。
- 驗證真實 Gregorian calendar date，包括閏年。
- 以批次開始時固定的臺北當地日期比較，不逐檔重新取得今天。
- 欄位6、13及非空欄位14都必須嚴格 `< 今天`。
- 非空欄位14另須 `> 欄位13`。

### 國民身分證與新式外來人口統一證號

共用純函式模組負責：

1. ASCII 大寫化。
2. 欄位5接受 `[A-Z][1289][0-9]{8}`；欄位11只接受 `[A-Z][12][0-9]{8}`。
3. 首碼地區代碼轉換。
4. 檢查碼。
5. 欄位5第二碼 `1/8` 對應欄位8的 `1`，第二碼 `2/9` 對應欄位8的 `2`。

檢查碼只能驗證邏輯格式，不能證明該人或證件真實存在。

## 8. 自動 decoder

不提供手動 decoder 或 encoding 選項。每個檔案獨立決定：

1. 依副檔名選擇 ZIP、XLS、XLSX adapter，再由各 parser 驗證容器內容；副檔名不會跳過安全解析。
2. CSV 依 BOM、嚴格 UTF-8、UTF-16 byte pattern、嚴格 BIG-5E 的固定順序判斷。
3. `.txt` 必須通過官方 BIG-5E 對照、換行及 208-byte record 檢查。
4. 使用的 decoder 與可信狀態存入內部檔案 metadata，但不作為一般 UI 模式或固定資訊區。
5. 只有副檔名與內容衝突、可信度不足或無安全 decoder 時，才在該檔案的 issue 中說明判定結果。

## 9. 批次、ZIP 與路徑

### 支援輸入

同一個 file picker 接受 `.csv`、`.xls`、`.xlsx`、`.txt` 與 `.zip`。`.xls` 與 `.xlsx` 都歸為 `XLSX`；ZIP 只是一個容器，entry 依自己的格式分類。

每個由使用者選取的來源檔案上限為 100 MiB。ZIP 內每個 entry 的宣告與實際展開大小也各自以 100 MiB 為上限；不限制單一 ZIP 或整個工作區的累計輸入大小。

目前輸入格式的 regular files 顯示在以所選格式命名的分頁（`TXT`、`CSV` 或 `XLSX`），並進入解析、預覽與輸出；其他已成功加入的支援格式顯示在「其他檔案」。symlink、不支援項目、重複檔案及無法開啟的來源不保存於工作區，只在該次新增結果依原因分類列出。切換輸入格式重用已保存項目，不重複上傳。

所有支援的 regular file 預設保留；使用者可逐檔移除，也可從頂層移除一般檔案或整個 ZIP 來源，另可一次全部清除。這些操作不修改原始檔案。普通多檔選擇沒有原始資料夾資訊，因此各自置於頂層；ZIP 內安全相對路徑會保留。

### ZIP 安全限制

- ZIP 巢狀深度上限 10。
- 虛擬資料夾深度上限 10，批次根目錄不計。
- 不追蹤、解壓或輸出 symbolic link。
- 拒絕絕對路徑、磁碟機前綴、NUL、控制字元及 `..`。
- ZIP 輸入 entry 累計上限 5,000；另限制每個 entry 的宣告與實際展開大小，以及實際輸出 bytes；輸入不設累計大小上限。
- 不只信任 ZIP header 宣告的大小。
- Reader 依中央目錄逐項走訪；遇到巢狀 ZIP 立即深度優先進入，regular file 一次只展開、解析及保存一個，完成後釋放該 entry bytes。各格式 parser 契約不因 ZIP 改變，Excel 仍採既有整份 workbook 行為。
- symlink 與不支援副檔名記為 warning；不安全路徑、同名路徑、加密、未知壓縮法、單檔過大、超深巢狀、損壞 entry／nested ZIP 或格式解析失敗記為該 entry 的 error，丟棄該項並繼續安全的 sibling。這些項目不計入已加入檔案數。
- 無法信任的頂層 ZIP 結構、ZIP64、分割式 ZIP，以及輸入 entry 累計超過 5,000 仍會使整個來源失敗；已在 worker 暫存的同來源檔案會回滾。
- 任何輸出路徑碰撞都顯示 error，不自動重新命名。
- 檔名先採 UTF-8 flag，再採 CRC 相符的 Unicode Path；未標示的非 ASCII 名稱才推測 CP950／CP437，並在內部保存原始 bytes、decoder 與可信狀態，不另顯示編碼警告。

ZIP 與資料夾依子節點聚合嚴重程度：`error > warning > valid`。錯誤與警告同時存在時仍各自顯示計數，並以 `·` 分隔；色彩只採最高嚴重程度。

## 10. 工作流程

頁面不使用方向 tabs，依固定順序呈現四個 section。

### Section 0 — 選擇格式

- 兩個原生 dropdown 分別選擇輸入與輸出；可見選項只有 `TXT`、`CSV`、`XLSX`。
- 輸入與輸出可任意組合，選擇只改變 active family 或 serializer，不重建已解析 IR。
- 一句固定高度摘要清楚說明「將把 X 檔轉換成 Y 檔」，避免選擇後版面位移。

### Section 1 — 輸入檔案

- 提供單一 multiple file picker，接受 CSV、XLS、XLSX、BIG-5E TXT 與 ZIP。
- 再次選取會追加至目前工作區，不覆蓋已載入的檔案。
- 每個檔案右側提供清楚標示的移除按鈕，單檔移除可復原，整個來源與「清空清單」先顯示原生確認對話框；所有操作只影響瀏覽器記憶體。
- 每次 file picker 選取都是一個暫存批次；全部檔案完成後才一次加入工作區、虛擬目錄樹、預覽與輸出。取消時捨棄該次所有已處理與未處理結果，先前工作區不變。
- 檔案選擇區只保留固定說明與「新增檔案」、「清空清單」，不承載處理狀態。其下方永遠保留單一具有固定最小高度的資訊區，統一顯示初始提示、延遲處理、成功／部分失敗、取消、清空及移除復原；一般文字大小下避免狀態切換造成版面位移，放大文字、縮窄畫面或內容換行時則自然增高，不得與下方內容重疊。
- 新增開始後立即鎖定檔案選擇與其他清單變更，但「清空清單」除重設執行中外始終可用，作為可中止目前工作並重設主要工作區的強制操作；前 300ms 保留原本外觀與既有資訊，若尚未完成才在固定資訊區顯示 spinner、進度文字與「取消本次新增」。快速批次直接切換到結果，不閃現處理文字或 disabled 外觀。
- 新增、取消與清空各自具有明確且互斥的操作狀態；新增超過 300ms 才顯示處理標題與 spinner。移除與復原不建立等待狀態：畫面與 client journal 先同步套用使用者意圖，worker 成功後才公告完成；若一般 request 失敗則回滾，若 worker 中斷則由 journal 復原，不短暫顯示已移除的項目。清空可中止任何主要工作區操作，舊操作結果不得回寫。
- 新增結果只摘要該次加入目前格式與「其他檔案」的數量，不重複工作區總數。未加入項目與操作錯誤在操作卡內容欄使用共用文字型 `+／−` 開關；展開後由同一實色浮動面板覆蓋下方內容並只在外層捲動，不增加頁面高度。點擊面板外或按 Escape 會收合；一般 UI 不顯示 parser、codec、bytes、代碼或 stack。
- 「全部標示為已查看」、處理取消與移除復原都是固定資訊區的情境操作。資訊區右側保留兩個固定操作欄位：全部已查看固定在左欄，只要仍有未查看檔案便持續顯示；右欄只顯示當下操作，包括未加入明細、取消或復原。桌面維持兩個固定欄位，中等寬度改為兩個等寬欄位，最窄時依 DOM 順序堆成單一全寬欄；單一動作在桌面使用右欄。檔名、數量、按鈕顯示與隱藏都不得改變欄位位置。移除後立即提供「復原」；處理與取消不移動一般完成焦點，取消完成後焦點回到「新增檔案」。
- 所選格式分頁直接顯示 `TXT`、`CSV` 或 `XLSX`，與「其他檔案」分頁都顯示穩定數量。頁籤使用固定外框、等寬選項與凸顯目前選項的 segmented control；切換時只替換兩個相同高度的檔案清單，不對整個分頁做淡出或延遲隱藏。
- 兩個分頁共用相同的 24rem 清單 viewport、sticky 表頭／表尾、sticky 檔名欄、移除按鈕與 site tokens；只有實際欄位內容不同。兩個表格的檔名欄及整體內在寬度必須一致，使同一 viewport 下的水平捲軸占位、空清單文字與表尾位置不因切換分頁而改變。
- 預覽位於兩個檔案清單分頁之外，只在所選格式分頁啟用時顯示；切到「其他檔案」時立即隱藏但保留目前高度與頁面捲軸幾何，切回後保留原本檔案、篩選、頁碼及捲動狀態並短暫淡入，不重新請求或清空內容。
- 初始載入、逐檔移除、清空清單或切換格式造成的空清單，都在同一表格本體置中顯示「目前沒有 TXT／CSV／XLSX 檔案。」或「目前沒有其他檔案。」，並保留表頭、表尾及完整高度。
- 「其他檔案」只顯示已成功加入、但不屬於目前輸入格式的 `TXT`、`CSV` 或 `XLSX`。未加入的項目不建立來源、清單列或可復原項目；新增結果訊息依「重複檔案」、「不支援的檔案類型（副檔名）」、「受密碼保護」及其他可採取行動的原因分組列出檔名。ZIP 不成為處理格式。
- Tree table 保留 disclosure、縮排、文字狀態與 `error > warning > valid` 聚合，不只使用顏色。
- 欄位依序為檔案、空白列、無法解析、資料、正確、錯誤、警告、已選、目前輸出問題與移除；來源、資料夾與總計列都由子檔案即時計算。
- 尚未由使用者開啟的檔案顯示可累計的精簡「新X」徽章，例如 `新1`、`新3`；徽章只保留必要寬度，把檔名欄的主要空間留給檔名。未加入項目只存在於固定資訊區的該次分類結果，不進入 tree 或「其他檔案」。
- 點選 regular file 後，在同一區顯示該檔案的 IR preview 與 error／warning。
- 切換 regular file 時保留目前預覽的完整高度與內容，但暫停其中的操作；新分頁資料到達後才一次更新檔名、路徑、表格與控制項，期間不得清空預覽或造成頁面捲軸跳動。過期的非同步結果不得覆寫目前選取檔案。
- 首次預覽、換檔、換頁、篩選或輸出格式檢查期間都使用同一個預覽區：已有內容時保留並暫停操作，尚無內容時在固定位置顯示準備提示。要求失敗時保留既有內容並解除暫停，不把預覽收合成空白。
- 預覽不因 input adapter 改變版面，也不建立來源格式資訊 panel。

#### IR preview

檔案樹保留安全目錄順序。選取單一檔案後，以 15 欄表格顯示共用內部表示：

- 預設順序為 rejected、error、warning、valid；同級依原始來源列號。
- 每頁最多 100 列，不提供一次顯示全部。
- 可篩選全部、無法解析、錯誤、警告、正確、未選取與目前格式輸出問題；自動修正由警告篩選涵蓋。每個選項都在固定寬度的選單內加註符合列數；0 列的選項仍保留位置但必須停用，可用與停用選項不得只靠顏色區分。
- 每列顯示「輸出」核取方塊；所有進入共同 IR 的資料列預設勾選，不因 error、warning 或自動修正而改變。
- 「輸出」表頭使用三態核取方塊選取或取消選取本頁；只套用至目前篩選結果的當前分頁，不改變其他篩選結果或頁面。
- 篩選器位於表格上方，桌面版頂端與左側檔名對齊，窄版才換到下方；它與其他 dropdown 共用外觀，只使用和預覽分頁按鈕相同的 compact 尺寸。分頁控制保留在表格下方，以單列顯示頁碼、列範圍及內容寬的上一頁／下一頁按鈕。
- 只請求並渲染目前頁面。
- 表格依固定 208-byte 欄寬與既有 padding 排版；列寬不依目前篩選、分頁或資料內容重新計算。
- Error cell 使用一致字重的紅色文字、淡紅背景與左側邊框；warning 與自動修正 cell 使用黃色文字、淡黃背景與左側邊框。
- 不只使用顏色，必須同時提供圖示、文字或邊框。
- 每筆有問題的資料後方提供預設收合的全寬說明；預覽不另設問題欄，點擊狀態儲存格即可展開，也可用鍵盤操作。不提供 hover tooltip。
- 預覽中的無法還原 PUA、decoder 替代位置，以及所選 TXT 無法編碼的位置以 `■` 顯示；展開說明顯示 byte 或 `U+XXXX`。`■` 不得進入 IR 或輸出，使用者原本輸入的 `？` 仍顯示為 `？`。
- 無法解析的列顯示原始證據，不提供輸出核取方塊；技術代碼、byte 或 decoder 細節置於「查看技術資訊」。
- Error／warning 清單以完整邏輯資料列為單位，不把同一列拆成 15 筆 cell issue table；有問題的 cell 以文字與背景色標示，不使用底線，跨欄規則會標示全部相關欄位。
- 格式錯誤顯示可直接採取行動的繁中說明；空值明確顯示「此欄位不能空白」，不向使用者顯示 regex。格式未通過時，不再疊加日期有效性或證號檢查碼錯誤。
- UI 只顯示欄位編號。
- 除非發生 decoder issue，預覽不另設來源格式或轉換方向資訊區。

### Section 2 — 下載結果

- 不提供格式選擇；只顯示 Section 0 已選的 `TXT`、`CSV` 或 `XLSX`、簡短下載狀態、返回 Section 1 查看問題的連結與下載按鈕。
- 下載卡保留既有狀態標題，並以一般說明文字顯示格式、輸出檔案、已勾選列與略過檔案摘要；不重複加入檔案、等待或按下載按鈕等已由流程、狀態與控制項表達的指示。問題、提醒與操作錯誤都由共用 `+／−` 浮動面板顯示完整內容；主卡只保留簡短狀態與下一步。
- 背景檢查或建立下載時，在固定下載狀態標題旁顯示 spinner 並停用下載；實際建立時沿用摘要位置，以「已完成 `current / total` 個檔案」顯示逐檔進度，完成後沿用同一位置更新結果，不造成版面位移。
- 下載卡沿用右側兩個固定操作欄位：左欄固定為下載，右欄固定為「取消下載」。取消按鈕始終顯示，只在建立下載時啟用；取消會在目前檔案完成序列化後停止，不儲存部分結果，單一 XLSX 仍須等目前 workbook 完成。
- 輸出格式變更的背景檢查必須明確進入 loading、ready 或 error；失敗時停止 spinner、保持下載停用並提供重試方向，不得永久停留在處理中。
- 建立下載期間若 Section 0／1 改變 active family、檔案或勾選列，舊結果不得儲存，並顯示「工作區已在建立下載期間變更，請重新下載。」；只要目前工作區已可下載，按鈕必須立即恢復可用，不得由這則提示持續鎖住。
- 建立多檔 ZIP 時，影響目前輸出的操作一開始就停止舊輸出；worker 在目前檔案完成後中止，不繼續建立整個 ZIP，也不儲存部分結果。單一檔案序列化仍只能在該檔案完成後合作停止。
- Loading、ready、error 與建立下載屬於 Section 2 自己的狀態，不寫回共用工作區；Section 0 只同步發布格式選擇。
- Section 1 tree table 的輸出問題欄隨 Section 0 輸出選擇更新，只計 fatal output findings；非阻擋的 `？` 替代只在受影響列與下載提示顯示。
- 選擇只切換 output codec，不重新解析來源或建立第二份 IR。
- Section 2 只對目前勾選列執行格式相容性檢查。BIG-5E TXT 對無 mapping Unicode 逐字以 `？` 代替，再檢查 byte 寬度；mapping 與局部來源 byte 問題本身不阻擋任何格式，替代後 overflow 才是 fatal。
- TXT 替代提示由 Section 1 預覽列出虛擬檔案路徑、來源列、欄位、`■` 及 Unicode code point。Section 2 保持下載可用並明說有幾列會以 `？` 代替；fatal count 不包含這些列。
- 選擇變更可在背景預備對應 codec，但不得顯示吵雜的 live-region resource 訊息。
- 可在驗證完成前選擇格式；任何仍會阻止下載的問題都停用下載，問題摘要保持可見，完整清單預設收合。
- Error／warning 列依預覽中的逐列勾選決定是否輸出；單一檔案直接下載，兩個以上檔案以 ZIP 保留安全虛擬目錄。
- 完全沒有勾選列的檔案不建立輸出 entry，也不阻擋其他檔案；Section 2 摘要明確顯示略過數量。全部檔案都沒有勾選列時仍不建立下載。

### Section 3 — 進階輸出

本區提供一條獨立的進階 XLSX 整理流程：

Section 3 明確是最小可運作模型（minimal working model），沒有 error、warning 或 validation gate。只要來源解析完成、至少有一列已勾選且參照 workbook 可讀，就允許下載；任何逐列資料問題、重複或未命中都不形成 gate。

- 使用者在本區另選一個參照 Excel workbook；它不是 Section 1 的批次來源，不加入來源檔案樹。
- 參照 Excel 與其他使用者選取的檔案共用 100 MiB 單檔上限。
- 讀取參照 Excel、整理查詢結果或建立進階 XLSX 時，在對應的固定狀態標題旁顯示 spinner 並停用下載；實際建立時沿用說明位置，以「已完成 `current / total` 個檔案」顯示逐檔進度；動畫遵守 reduced-motion。
- 參照 Excel 與進階下載各自保存錯誤；讀取或工作表錯誤只顯示在參照卡，整理或下載錯誤只顯示在下載卡，不另設共用錯誤區。主卡顯示簡短錯誤與「請再試一次。」；完整原因預設收合。
- 第一列作為 header；空白 header 以欄序補名，重複 header 以序號區分。多工作表 workbook 由使用者選擇一張。
- 第一次使用時不預先勾選附加欄位。之後只以本機 salt 加上完整 header 文字的 SHA-256 fingerprint 還原查詢欄與附加欄；只命中相同 header 的欄位，未命中者保持未勾選，查詢欄未命中時沿用自動選擇。這項記憶行為不另在主要畫面顯示說明。
- 進階流程只讀取目前所有勾選列的 final value，不回寫或改變 Section 1／2 的資料、issue 或標準輸出。
- 每列先輸出欄位5、欄位6、台北目前年份減欄位6年份所得的約略年齡，以及欄位7至欄位12。欄位8在此輸出投影中套用 `1 → 男`、`2 → 女`，其他值原樣保留；Primary row 不依欄位5去重。
- 使用者選擇 reference key 欄與要附加的 reference 欄。Primary 欄位11與 reference key 都以 trim＋大寫後比對。
- 每個 primary row 獨立執行 left join。Reference key 多筆命中時依 reference row order 展開為多列；未命中時仍保留 primary row，附加欄位填空白。
- 進階下載卡顯示狀態、檔案／列摘要、簡短下一步與預設收合提醒清單。Reference 的空白標題、重複標題與未儲存公式結果依類型合併為有界的白話摘要；讀取提醒、重複與未找到參照資料都不阻止進階下載。只有來源仍在解析、沒有勾選列或 reference workbook 無法解析時不能建立結果。
- 輸出單一 `進階輸出-YYYYMMDDHHmm.xlsx`，worksheet 名稱為 `整理結果`，時間使用 `Asia/Taipei`。
- 參照 workbook 與 lookup 結果同樣只保留在目前瀏覽器記憶體中。
- 清空 Section 1 只移除主要工作區資料；已選的 Section 3 參照 Excel 仍保留，並把查詢結果更新為零列。只有 Section 3 的「移除」會清除參照 Excel。

### 流程後方 — 欄位規則與說明

- 固定 15 欄、208 bytes、寬度與 validation hook 位於 Section 3 後方的原生 disclosure。
- 初始收合，只顯示摘要；展開後仍只顯示欄位編號與技術規格，不顯示業務欄位名稱或真實資料。

## 11. 輸出

使用者在 Section 0 為整批選擇一種輸出格式：BIG-5E TXT、CSV 或 XLSX。這個選擇不改變正規化、自動修正或 IR 的 error／warning；它會建立獨立、非持久化的 output findings。只有 blocking finding 影響 fatal count 與下載資格，非阻擋替代另行提示。

### BIG-5E TXT

- 每列固定 208 bytes。
- 所有值靠左，右側以 `0x20` 補齊。
- 每列後接 CRLF，包括最後一列。
- 依固定的數位發展部 CNS11643／BIG-5E 對照表編碼，不使用 HKSCS fallback。
- Unicode 沒有官方 BIG-5E 對照時，TXT 逐字輸出全形 `？` 並顯示非阻擋提示；共用 IR 不改寫。
- 以替代後 bytes 檢查欄寬；超出時為 fatal output error。

### XLSX

- 每個邏輯值以文字寫入。
- 不加入標題列。
- 保留前置零，不轉為數字、日期或布林值。

### CSV

- 使用 UTF-8 BOM，換行固定為 CRLF，不加入標題列。
- 依 CSV 規則保存最終 IR 的文字值，處理逗號、雙引號、多行文字與空值。
- 不加入公式、前置 apostrophe 或其他試算表專用 wrapper。CSV 沒有儲存格型別，試算表軟體直接開啟時可能自行轉型；需要可靠文字型別與前置零時使用 XLSX。

### Batch ZIP

- 每列都有是否輸出的明確決策；所有進入共同 IR 的資料列預設輸出，使用者可在預覽取消勾選。
- 工作區只有一個檔案時直接下載所選格式；兩個以上檔案時才建立 ZIP。
- 批次 ZIP 輸出項目上限為 5,000；每個已產生 entry 上限為 100 MiB，最終 ZIP 上限為 500 MiB。輸出 entry 的未壓縮 bytes 不另設累計上限。
- 完全沒有勾選列的檔案會在摘要中明確計為略過，不建立 entry，也不阻擋其他檔案。其餘要輸出的檔案若仍在處理、無法讀取、含無法解析來源記錄或檔案層級 error，仍阻止下載。
- 建立 ZIP 前先檢查項目數、安全路徑、碰撞與輸出資格；之後一次只 materialize 一個檔案，檢查單檔大小後立即加入 ZIP、釋放暫存並讓出 worker event loop。CSV／TXT entry 使用 DEFLATE level 6；已壓縮的 XLSX entry 以 store 保存。
- ZIP writer 直接把輸出 chunks 組成 `Blob`，不再把所有 chunks 串接成另一份 `Uint8Array`；瀏覽器下載沿用同一個 `Blob`。超過 500 MiB 或取消時丟棄未完成結果。
- 所有保留檔案的輸出副檔名依批次輸出選擇統一改為 `.txt`、`.csv` 或 `.xlsx`。
- 保留安全虛擬目錄；巢狀 ZIP 名稱保留為資料夾 segment。
- 標準與進階輸出都先依 NFC 正規化後的安全虛擬路徑排序；同一組檔案與列選擇不得因 picker 選取、移除或復原的先後順序而改變輸出內容。
- ZIP 檔名為 `<output-codec>-<YYYYMMDDHHmm>.zip`，時間在下載時以 `Asia/Taipei` 產生，例如 `big5-txt-202608041530.zip`。
- 輸出路徑碰撞顯示 error 並停止，不覆寫或自動重新命名。
- 不保留來源權限、symlink 或不必要的時間 metadata。

## 12. 隱私、安全與可及性

- 不建立 upload endpoint、帳號、遙測或第三方 runtime connection。
- 正式資源全部由同源提供並可離線使用。
- 不把檔案內容、路徑、issue、內部表示或輸出放入 localStorage、IndexedDB、URL 或 log。localStorage 只保存 theme，以及 Section 3 的本機 salt、查詢欄 fingerprint 與附加欄 fingerprint；不保存 header、檔名或工作表名稱。
- 預覽僅呈現目前選取檔案及分頁資料。
- 解壓、解析、正規化、驗證、輸出檢查與序列化都在單一 dedicated worker 內完成；主執行緒只保存清單摘要及目前最多 100 列的預覽頁。清空主要工作區會推進 workspace epoch，清除 worker 內的主要檔案與預覽 cache，但保留 Section 3 參照 Excel；舊 epoch 的結果不得回寫。
- `batch-client.ts` 在目前頁面生命週期內保留已公開來源的原始 `File` 參照、接受項目清單、已取消勾選列及 Section 3 參照檔／工作表，並以 `ready → recovering → ready／failed` 管理唯一 worker 狀態；不複製 compact IR，也不寫入持久儲存。私有 message channel 只負責 Worker、request ID 與 pending promise。未預期錯誤會停止舊 instance、鎖定全站並重建 journal；復原完成才恢復操作，不得以空 worker 搭配舊摘要。
- 可安全重試的長操作在鎖定畫面期間靜默復原並重試一次；再次中斷時只讓該 action 顯示「這項操作在自動重試後再次中斷。」，已恢復的 worker 仍保持 `ready`。journal-backed 移除、復原與列勾選由重播完成；preview 與輸出檢查等衍生讀取在 `ready` 後依目前 UI 重新查詢。閒置時復原超過共用 300ms delay 才顯示全站 modal「正在處理背景資料」；只有 `failed` 顯示 error tone 的「無法處理背景資料」。各 section 不保存 worker state 或顯示 worker 文案；錯誤內容只放在預設收合的「查看詳細資料」，固定操作只有「重新載入」。
- 狀態變化以簡潔事件訊息回報，不逐列在 live region 宣告。
- 格式選擇、檔案分頁、樹狀清單、問題 disclosure、分頁、水平捲動與下載必須可用鍵盤操作。
- 控制項使用清楚完整文字；問題與警告由狀態儲存格明確提示，完整說明預設收合，技術細節再按需展開。表格 viewport、spinner slot、摘要高度與捲軸空間預留，避免內容切換造成不必要位移。
- 各區 dropdown、標題與說明共用同一套視覺階層；只有預覽篩選使用 compact 尺寸。附加參照欄位保留 fieldset／legend 語意，但不另加外框或浮在邊框上的標題樣式。
- 檔案選擇、檔案操作、標準下載與進階下載使用同一種操作卡片階層：標題、說明與右側兩個等寬操作欄位固定對齊；只有一個下載按鈕時放在最右欄。桌面 action rail 對齊標題列；所有 action detail 使用同一組 markup、文字型 `+／−`、tone、實色面板、外點與 Escape 行為，各 section 不覆寫樣式或開合。浮動模式只由共用設定啟用，開合不改變頁面高度或按鈕位置；worker modal 使用同一 detail box 的 inline 模式。窄畫面依閱讀順序自然換行。主要操作保留一般控制高度，只有預覽分頁使用同色彩、邊框與焦點樣式的較小按鈕。載入 spinner 在標題旁保留固定 inline 空間，顯示或隱藏不得改變文字、卡片高度或按鈕位置。
- 動畫遵守 reduced-motion，狀態不只以顏色表達。
- 格式摘要、固定資訊區、預覽、提示、下載狀態與進階輸出共用同一個短暫 settle transition：舊內容保留至新狀態可一次提交，新內容只從接近完整的不透明度淡入，不先淡出、不動畫 `display`、visibility、尺寸或位置。新增、標準下載與進階下載共用簡短的「已完成 `current / total` 個檔案」進度句型；只在語意狀態或目前處理檔名改變時觸發 transition，不因進度數字或一般 render 重播；reduced-motion 時立即更新。

## 13. 不做的事

- 舊設定 JSON 或 settings v3 migration。
- 可編輯欄寬、必填、預設值、對齊或空白策略。
- 手動 decoder 選擇。
- 任意 schema designer。
- 靜默輸出部分成功檔案。
- 靜默截斷、補零、修正 checksum、改名或路徑展平。
- 伺服器端處理或雲端同步。
